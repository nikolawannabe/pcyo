Group Badges

Every concert or event is marked with the group putting it on. The badges appear on event cards, event pages, and the PCYO and SCO rows of the calendar on the classes page. A joint event shows both badges, host first. Set the group with org in data/terms.yaml (or in an event's front matter), e.g. org: SCO or org: [SCO, PCYO].
